# Laboratoire 3D · réseau virtualisé

Démonstration interactive : https://jessem8.github.io/virtualization-lab-3d/

Deux PC, cinq VM, des VLAN et un pare-feu, racontés par un paquet qui circule. La maquette est une simulation explicative de l’architecture prévue : elle ne configure aucune machine et ne mesure aucun trafic.

Ce dépôt ne contient que la version publiée du présentateur ; les sources sont générées depuis le dépôt du projet. Notices des bibliothèques et polices dans `network-assets/*-LICENSE.txt`.
